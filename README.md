# 🐍 Bolsa Futuro Digital – Python  
Repositório dedicado ao armazenamento e organização de todas as minhas atividades de prática realizadas durante o **Bolsa Futuro Digital**. Projeto desenvolvido pelo Governo Federal com objetivo de formar programadores em diversas linguagens.

Aqui você encontrará desde exercícios introdutórios de manipulação de strings até aplicações mais completas de desenvolvimento de software.

---

## 📚 Objetivo do Repositório
Este repositório serve como um **portfólio de aprendizado** e **diário de estudos**, reunindo:
- Práticas guiadas e exercícios;
- Pequenos projetos com Python;
- Exploração de conceitos fundamentais e intermediários;
- Evolução contínua em lógica de programação, boas práticas e estrutura de código.

---

## 🧰 Conteúdos Incluídos

### 🔤 Manipulação de Strings  
- Fatiamento  
- Métodos de limpeza e transformação  
- Expressões regulares  
- Formatação de texto  

### 🔢 Estruturas de Dados  
- Listas, tuplas, dicionários e sets  
- Iterações e compreensão de listas  
- Ordenações e filtragens  

### 🔁 Estruturas de Controle  
- Condicionais  
- Loops `for` e `while`  
- Tratamento de exceções  

### 📦 Funções e Modularização  
- Criação de funções  
- Argumentos, parâmetros e retornos  
- Modularização de código  
- Escopo e boas práticas  
- Uso de bibliotecas padrão e externas (como `random`, `datetime`, `requests`, etc.)

### 🧪 Introdução a Testes  
- Testes básicos com `pytest`  
- Boas práticas de validação de funções  

### 🛠️ Desenvolvimento de Software  
- CRUDs simples  
- Miniaplicações em console  
- Organização em pacotes  
- Princípios iniciais de arquitetura e versionamento
- DAO (Data Access Object)
- POO (Programação Orientada a Objetos)
- Classes e objetos  
  - Atributos e métodos  
  - Encapsulamento  
  - Herança  
  - Polimorfismo  
- SQL e manipulação de bancos de dados

### 🌐 Desenvolvimento Web  
- Framework Django (estrutura de projetos, apps, views, templates, models, rotas) 
- HTML básico (tags, estrutura, semântica)
- CSS básico (estilos, classes, seletores)
